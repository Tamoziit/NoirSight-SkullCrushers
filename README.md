### ⚙ *1. API Wrapper for Social Platforms*

We built an *npm-based wrapper* for platforms to install with an API key from us.

🔗 *What it does:*

* Acts as a *content moderation layer* between uploader and platform
* Uses *EfficientNet* and *VisionTransformer* to flag:

  * Deepfake images
  * Manipulated videos
* Adds model *confidence levels*, flags on posts, and public feedback counts
* Also includes our *AI-powered Social Media News Analyzer*:

  * Extracts the post text or link
  * Compares it to real-time news using scraping + LLMs
  * Determines if it’s *factual or contextual* with explanations and source links

🧠 All this is *as simple as adding one wrapper* — and platforms get instant moderation power without building the system themselves.
